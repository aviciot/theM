## Rollback Method

All changes are documentation-only (Markdown files, no application code). The complete rollback method:

```bash

git checkout HEAD~1 -- docs/architecture-v2/<filename>

# Restore go/docs/architecture-v2/ if deleted
git checkout HEAD~1 -- go/docs/architecture-v2/

# Full rollback: revert the consolidation commit
git revert <consolidation-commit-hash>
```

Since consolidation should be one commit, a single `git revert` restores all files exactly.
