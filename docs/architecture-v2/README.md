architecture documentation. All active architectural records, ADRs, runbooks,
implementation status, and lessons learned live here.

## Current Handover Location

**Active handover:** `NEXT_SESSION_BRIDGE_HANDOVER.md`

This file contains the current HEAD, route ownership table, test totals, and the
exact first prompt for the next session. It is updated at the end of each session
per the handover procedure in `../CLAUDE.md`.

When a new handover is written it replaces the content of this file (or is written
to `NEXT_SESSION_HANDOVER.md` as specified in `../CLAUDE.md`). The old handover
moves to `archive/`.

## Documentation Update Rules

| Change | Update |
|---|---|
| New package or significant package change | `implementation-status.md` (package inventory + test count) |
| New route or route ownership change | `implementation-status.md` (route map) |
| Non-obvious behavior or platform trap | `lessons-learned.md` |
| Major architectural decision | New `adr-NNN-*.md` file |
| Operational procedure change | Relevant runbook file |
| New deferred schema change | `schema-migrations.md` |
| Session end or subsystem boundary | New handover per `../CLAUDE.md` session lifecycle rules |
| New Go test | `go/TEST_INDEX.md` (same commit) |

**Rule:** documentation updates go in the same commit as the code change.
Stale docs that contradict the code are a bug.
